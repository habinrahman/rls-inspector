### Added

- Visual RLS policy debugger for Supabase (React + Vite SPA)

- Four `SECURITY DEFINER` SQL helpers (`setup_supabase_functions.sql`)
- Comprehensive README with architecture diagrams
- Vitest unit tests for the analysis engine
- GitHub Actions CI (build + test + audit)
- Community health files, issue/PR templates, Dependabot
- GitHub release workflow
